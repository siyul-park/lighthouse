# lighthouse-report

Renders what a run found: text, SARIF and the agent format (findings grouped by decision), fix proposals, and the generated documentation of the decisions.

**Layer.** L3; depends on model and spec. Never on ml or store (session converts).

## Entry points
- `render`, `render_with`, `Format` (`Text`, `Sarif`, `Agent`): diagnostics to text.
- `agent_report`, `AgentReport`, `Briefing`, `Detail`: the JSON the agent reads, grouped by decision.
- `Grouped`, `GroupOptions`, `Entry`: findings grouped by decision.
- `docs::pages`, `decision_markdown`, `fix_operations_markdown`: the pages under `docs/decisions`.
- `docs::OPERATIONS`: the reference of fix operations.

## Invariants
- An incomplete analysis is stated in every format: text prints `incomplete` lines and SARIF marks the invocation unsuccessful.
- Output is deterministic in the order given; text ends with a `summary:` line whenever there is anything to report.
- Generated pages carry a `Generated by lighthouse docs generate` header, and `lighthouse docs check` fails when a committed page differs, so a decision edit means regenerating `docs/decisions`.
- Presentation only: no analysis and no file I/O.
